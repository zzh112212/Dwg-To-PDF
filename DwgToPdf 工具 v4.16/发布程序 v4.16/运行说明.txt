  DWG 批量转 PDF 工具  运行说明  v4.15
════════════════════════════════════════════════════════

一、版本定位
  v4.15 = v4.14 + **含图片图纸的高清出图**（新增设置项「含图片图纸的高清出图」）。
  原理：accoreconsole 的 -EXPORT **不认打印质量/设备**（图片被压到 ~26-44dpi），
  故**真光栅图片**图纸改走 **COM（AutoCAD 打印）路径 + 现场生成的高清 pc3**（认"光栅图像质量"）。
  实测（全量 183 张，2026-09-16）：图片 PDF 内像素 28dpi → **166dpi**（≈6 倍）；
  整批墙钟 744.1s（不含该功能的基线 725.3s，+2.6% 在噪声内），181/181 成功、0 失败。
  详见《经验手册》第26章。
  v4.14 = v4.12 修订 + **识别扫描优化**（仅识别脚本 extframe.lsp 改动）：
  阶段1 图框识别更快（逐文件 -46%~-65%，全量整批约 -8%）；
  识别结果与 v4.12 修订**逐条完全一致**，使用方式、日志与界面无任何变化。
  v4.12 修订（2026-09-13）：**识别完整性修正**——图框识别"只抓到图内小矩形"
  的图纸不再被裁（自动改用整幅图纸范围出图），并在图框外仍有内容时明确提示。
  此前各版本的全部修复均已保留。

二、v4.15 变更（用户可见）
  1. 新增设置「含图片图纸的高清出图」：关闭 / 1200 / 2400（默认）/ 4800 dpi。
  2. 生效范围（重要）：仅**真含光栅图片（IMAGE）且图片文件可找到**的图纸——
     粘贴的图片（图片型 OLE）、PDF/DWF 参考底图**不**走高清通道；
     图片外部文件缺失的图纸也不走（实测这类图纸走打印通道会出空白页，故自动回避）。
  3. 该类图纸出图改用 AutoCAD 打印通道（单张更慢），图片明显更清晰；
     阶段1 日志会列出"含光栅图片(IMAGE)图纸 N 张"。
  4. 兜底：万一高清通道出图失败，工具会自动回退到原通道重出，不会漏图。
  5. 其余行为与 v4.14 一致（不含光栅图片的图纸输出不变）。

三、v4.14 变更（用户可见）
  1. 更快：**阶段1 图框识别提速**，大型图纸更明显。
     实测逐文件识别耗时：11 万实体图纸 3.53s → 1.23s（-65%）；
     2.2 万实体 0.61s → 0.27s（-56%）；全量整批墙钟中位数约 -8.7%。
  2. 识别结果不变：184 张双版本对照，识别框（坐标/来源/纸型）逐条完全一致；
     出图结果、日志文案、界面操作均与 v4.12 修订相同。

四、变更历史（v4.12 及其 2026-09-13 修订）
  1. 更快：205 张全量 21.9 分钟 → 15.0 分钟（-31.6%），全程不启动 AutoCAD
  2. 日志：阶段2 显示"已并入出图会话，无需预处理"；识别阶段逐张打印
     "[识别] n/N 文件名"
  3. 失败栏：右侧内容不再被裁；失败原因仅显示简短说明（如"疑似存在离群实体"），
     完整说明在日志中
  4. 大文件：设置项改为"文件超过多少 MB 时退回待转换"——超限文件本轮不转换，
     保留在「待处理」栏（不再判失败）
  5. 新增"单张转换超过多少秒时退回待处理"：超时自动中止该张并退回「待处理」
  6. 新增"合并待转换"按钮（待处理栏右侧）：把待处理文件复制到
     输出文件夹\待转换文件_时间戳\ 并打开
  7. 删除"长时转换提醒"（原超时仅提示，现改为"超时退回待处理"）
  8. 再次点击"开始转换"时，本轮忽略文件大小与转换时间限制——可直接补转
     上一轮退回「待处理」的文件
  9. 【2026-09-13 修订】被裁图纸自动修正：识别框没覆盖整幅图纸、且"整幅图纸
     本身就是一个块"（如 H47 总成图的 EQWE 块）时，自动按整幅图纸范围出图，
     不再裁掉图框边与标题栏。日志显示：
     "[信息] … 识别框未覆盖整幅图纸，已按全图范围出图（2235×1506mm），避免内容被裁"
     —— 此类图纸不必再手工勾选"识别块图框"。
 10. 【2026-09-13 修订】新增越界提示：图框外检测到其他内容、但不足以判定整幅
     图纸范围时，保持原识别框并提示：
     "[提示] … 图框外检测到其他内容（识别框 A×Bmm，全图 C×Dmm），出图可能缺内容，
      请人工确认"
     （常见于图纸旁另放了 3D 图片/表格的情形；可按提示人工确认图纸是否完整）
 11. 【2026-09-13 修订】出图顺序固定为"先小文件、后大文件"：小图先出，批量结果
     尽快可见；大图（高质量打印）排在最后，不阻塞前面绝大多数文件。
 12. 【2026-09-13 修订·重要】转换过程**不再修改源图纸**：此前版本在转换后会重写源
     dwg（文件时间/体积变化，并生成同名 .bak）。已修复为"绝不写回"，源文件保持
     原样（实测跑前跑后哈希一致）。如之前版本已在您的图纸目录留下 .bak 文件，
     可自行删除。

五、模式选择
  公司版（默认）：使用公司图框模板标准库快速匹配，识别率高、速度快。
  通用版：全模型逐层识别图框，适用于非标准图框。

六、运行前准备
  1. 本机需安装 AutoCAD（Core Console 由程序自动定位）；
  2. 六个文件须放在同一目录：DwgToPdf.exe、DwgToPdf.exe.config、
     extframe.lsp、extframe_company.lsp、公司图框标准库.json、运行说明.txt；
  3. 首次运行自动执行环境自检。

七、基本用法
  1. 将 DWG 文件（或文件夹）拖入窗口，或点击"添加"；
  2. 选择模式（公司版/通用版）与打印选项；
  3. 点击"开始转换"，进度与日志实时显示在窗口下方；
  4. 结束后按栏处理：
     · 「失败」栏 → 点"合并失败文件"集中复制（图纸本身问题，需人工处理）；
     · 「待处理」栏（大文件/超时退回的）→ 点"合并待转换"复制出来单独处理，
       或直接再点一次"开始转换"补转（此时本轮不受大小/时间限制）。

八、图框为块（INSERT）的图纸
 2026-09-13 修订起：整幅图框是一个块、且整幅尺寸能被最大纸型容纳的图纸，
 程序会**自动**按整幅图纸范围出图（日志出现"识别框未覆盖整幅图纸，已按全图范围
 出图"），无需任何手工设置。
 只有在下列情形才需要手工配置：块内没有闭合 LWPOLYLINE 等图框特征、或图框外
 还有散放内容（图片/表格）导致无法判定——此时日志给出"[提示] … 图框外检测到
 其他内容…"，可到「设置 → 识别块图框」勾选开关并把块名（如 EQWE）加入块名列表
 后重转。

九、注意事项
  - 【取值建议】"单张转换超过多少秒时退回待处理"与"文件超过多少 MB 时退回待转换"
    建议都保持 0（不限制）。程序并发出图，单张正常耗时约 10~30 秒（大图更久），
    阈值设置过小会导致大量图纸被中止退回、需要多轮"开始转换"补转，反而更慢。
    若要防"真卡死"，单张超时建议 ≥300 秒。
  - 「识别块图框」通常**无需勾选**：整幅图框是一个块的图纸已能自动修正（日志出现
    "识别框未覆盖整幅图纸，已按全图范围出图"）；勾选会让识别阶段明显变慢（约 +45%），
    仅在识别结果不完整且日志提示 BLOCKHINT 时才需要。
  - 大文件阈值与单张转换超时均在"设置 → 打印/输出"中调整（0=不限制）；
  - 图框识别结果缓存于输出目录 frame_cache.json，算法版本变更时自动失效重建，
    无需手动删除；
  - 日志同时写入 输出文件夹\logs\DwgToPdf_*.log。
