审计脚本使用说明（v4.12 归档）
================================================================

本目录存放批量出图质量审计脚本，全量转换跑完后可随时复用。
脚本为独立工具，不参与主程序构建；路径均走命令行参数，无硬编码。

一、脚本清单
----------------------------------------------------------------
纸型审计.py   纯标准库。递归扫描 PDF，读 /MediaBox 换算毫米，
              对照标准幅面（4A0~A4，容差 3mm），标出非标纸型。
              输出: 控制台 + <PDF目录>\纸型审计.txt

满版审计.py   依赖 PyMuPDF（pip install pymupdf）。渲染页面统计墨迹
              包围盒，计算四边留白，识别"偏小 / 偏移 / 空白页"。
              可疑张自动渲染 PNG 存 <PDF目录>\_满版可疑\
              输出: 控制台 + <PDF目录>\满版审计.txt

渲染预览.py   依赖 PyMuPDF。把 PDF 首页批量渲染 PNG 供人工查看，
              输出到 <PDF目录>\PNG预览\

二、典型用法
----------------------------------------------------------------
    cd "DwgToPdf 工具 v4.12\_审计脚本"

    :: 1) 跑完全量转换后，对输出目录做纸型核对
    python 纸型审计.py "...\全量输出\PDF文件"

    :: 2) 满版/偏移检查（DPI 72 即可，大图可降到 60 提速）
    python 满版审计.py "...\全量输出\PDF文件" 72

    :: 3) 需要人工看图时再渲染高清预览
    python 渲染预览.py "...\全量输出\PDF文件" 120

三、判定口径（与 v4.12 验收一致）
----------------------------------------------------------------
- 纸型: 与图纸幅面匹配的最小可容纳全出血纸（含窗口外扩 M=5mm）。
- 满版: 墨迹占页面对边 >= 60% 为正常；任一边留白 > 8% 判"偏移"。
- 空白页: 直接判失败（v4.12 质量核查会在引擎内拦下并走 COM 回退）。

四、历史背景
----------------------------------------------------------------
v4.12 验收时的审计脚本随临时输出目录一并清理，本目录为重建版
（2026-09-12），逻辑口径不变，路径参数化后更通用。
